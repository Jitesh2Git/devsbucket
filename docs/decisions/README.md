# Decision notes

Write one short note for each decision that changes how we build. Name it `NNNN-short-title.md` and never edit an old note: when a decision changes, add a new note that replaces it.

Template:

```md
# NNNN: Title

Date: YYYY-MM-DD · Status: accepted | replaced by NNNN

## Context

What problem or question led to this.

## Decision

What we chose.

## Why / alternatives rejected

Short reasons, plus what we considered and why we said no.
```
